# Security policy

## What Tracer does and does not do

Tracer reads source files in your workspace and draws diagrams locally. It makes no network requests, uses no AI service, and collects no telemetry. Its webview has no `http(s)` source in its Content-Security-Policy. See "Privacy and permissions" in the extension README.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting: **Security → Report a vulnerability** on https://github.com/prasanna-cw/Tracer. Include what you found, how to reproduce it, and the version (Extensions view → Tracer).

You will get a first reply within a few days. Fixes ship as a new Marketplace version and are noted in the changelog.

## Supported versions

Only the latest published version is supported.
